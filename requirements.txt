# Python dependencies for the eval_gnn_generalization_pg pipeline.
# Versions match the v3 campaign environment. torch/torch-geometric wheels are
# platform-specific --
# if the plain install fails, follow https://pytorch.org and
# https://pytorch-geometric.readthedocs.io for the right index URL.
#
# NOTE: Step 1 (grid conversion) additionally needs GNU Octave (a system
# package, not pip):  sudo apt-get install -y octave   # or: brew install octave

# users can skip it and start at Step 2.

# than floored because the DC baseline is version-sensitive: `rundcpp` does not
# write res_bus.q_mvar, and 2.x left the column as NaN while 3.x leaves the
# previous AC result there. The generator now zeroes the column explicitly (the
# Q == 0 convention), so the pin is for reproducibility, not correctness.
